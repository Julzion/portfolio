# TaskFlow

A simple drag-and-drop task board with **To do**, **In progress** and **Done** columns.

**Live demo:** https://brian-jules-asuncion.vercel.app/projects/taskflow/

## Features
- Add tasks with a priority (low / medium / high) and an optional due date
- Drag and drop cards between columns, or use the ← → buttons (works on phones and with a keyboard)
- Tasks sorted by priority, then due date
- Overdue tasks are highlighted
- Progress bar showing how many tasks are done
- Clear all completed tasks at once
- Board is saved in the browser with `localStorage`

## Built with
HTML5 · CSS3 · JavaScript (HTML Drag and Drop API, no frameworks)

## Run locally
Open `index.html` in any modern browser.
